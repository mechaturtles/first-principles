# First Principles

Personal, noncommercial courses by [Bryce Villanueva](https://mechaturtles.com) and [Grok Bot](https://x.ai/bot).

First Principles is its own category, alongside Demos. This repository is the writing home for that category. It is meant to hold more than one course. The pages here are a proposal backbone for Bryce to dictate into. They are not a finished curriculum, and they are not published as a site.

## Purpose

The teaching goal is funny and relatable above all. Courses use personal, everyday experiences to build understanding. A reader should come away able to explain the idea.

The first course to outline is **AI from first principles**. Prior FDE / kitchen work is an optional idea. It is not mandatory curriculum. What that work refers to is for Bryce to spell out.

Further courses, if Bryce wants them, would sit beside `courses/ai/` as siblings.

Writing in these files is labeled in three ways:

- **Direction already given** — choices stated for this backbone (category, voice, AI as the first outline, FDE / kitchen left optional).
- **Bryce input** — empty slots for Bryce's own words. Nothing autobiographical has been filled in.
- **Suggested editorial** — structure proposed for reaction. It stays a suggestion until Bryce adopts it.

Factual claims, when any are added later, need a primary source. Until that citation exists, mark the claim unknown.
