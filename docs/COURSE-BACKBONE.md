# Course backbone

**Status: provisional suggestion.** This is a reusable arc to react to. It is not a curriculum Bryce has approved. Any step can be dropped or replaced.

The same shape should be able to serve more than one course under First Principles. The first outline is AI. Other courses are future work.

Experiences, jokes, and examples belong to Bryce. This file does not supply them. It does not attribute quotations, and it does not narrate anyone's life.

## Suggested arc

**Suggested editorial.**

1. **A familiar moment.** Start from an ordinary situation a reader already recognizes. Funny when the moment supports it.
2. **The snag.** Name the part that feels obvious until someone tries to explain it.
3. **A few principles.** Keep only the smallest set of ideas that actually carry the explanation. The aim of this step is understanding.
4. **Rebuild the moment.** Walk back through that same everyday experience from those principles.
5. **Say it plainly.** The reader should be able to retell it in ordinary words.
6. **Where to go next.** The next beat in this course, or another course in the category, when there is one.

## What a later local pass should produce

**Suggested editorial.** When Bryce dictates into the placeholders and continues locally, that pass should produce the following for each course it takes on. Treat this list as provisional too.

- Reader-facing prose that follows an arc Bryce has accepted (the one above, or a replacement).
- The everyday experiences Bryce dictated, in his words, used as the way in.
- Understanding goals written as explanations a reader could give out loud.
- A sequence of beats whose order Bryce has set.
- A source note beside each factual claim, pointing at a primary source. Claims without a source stay marked unknown.
- A visible split between **Bryce input** and any **suggested editorial** line that is still only a proposal.
- Suggested lines either rewritten in Bryce's words or removed before they are presented as the course.

The AI outline to fill first is [courses/ai/README.md](../courses/ai/README.md). Open questions and the optional FDE / kitchen idea live in [IDEAS.md](IDEAS.md).
